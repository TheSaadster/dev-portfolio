# Portfolio — [thesaadster.vercel.app](https://thesaadster.vercel.app)

Personal portfolio built with Next.js, TypeScript, Tailwind CSS, GSAP, and React Three Fiber.

## Stack

- **Framework** — Next.js 14 (App Router)
- **Styling** — Tailwind CSS
- **Animations** — GSAP (ScrollTrigger), React Three Fiber, Lenis
- **Deployment** — Vercel

## Features

- About section with skills
- Project showcases (Chess It Up, Voice AI Assistant)
- Live YouTube channel stats via YouTube Data API v3
- Contact section
